# Layered Span Studio - 要件定義

## プロジェクト概要

Layered Span Studioは、multi-labelなNER（Named Entity Recognition）タスクに特化したアノテーションツールです。各ラベルに対してスパンを独立して記録できる機能を持ち、使いやすさとLLM連携を重視した設計を目指します。

## コア要件

### 1. 使いやすいアノテーションツール
- 直感的で分かりやすいUI/UX
- スムーズな操作フロー
- ストレスのないアノテーション作業環境

### 2. マルチラベル対応・独立スパン管理
- **重要**: あるラベルに対して、他のラベルとは独立してスパンを記録可能
- 複数のラベルが同じテキスト範囲に重複して付与できる
- ラベル間での干渉なく、自由にスパンを設定・編集
- この操作がやりやすいUI/UXを提供

### 3. LLMフレンドリーな機能
- **目的**: 人間がある程度アノテーションしたら、LLMがそれを読み込んで残りのアノテーションを自動化
- LLMが読み取りやすいデータ構造
- LLMへの入力・出力がスムーズに行えるインターフェース
- 詳細は後で詰める

### 4. キーボードショートカットの充実
- 操作の高速化のため、豊富なキーボードショートカットを提供
- マウス操作を最小限に抑えられる設計
- 頻繁に使う操作には直感的なショートカットを割り当て

## 追加機能要件

### データ管理

#### エクスポート/インポート機能
- **フォーマット**: JSON
- 標準的なデータ交換形式をサポート
- 詳細な仕様は後で決定

#### プロジェクト単位でのドキュメント管理
- プロジェクトごとにドキュメントを整理・管理
- プロジェクト間での切り替えが容易
- プロジェクト固有の設定を保存

### アノテーション支援機能

#### アノテーションガイドライン表示
- 作業中に参照できるラベル定義を表示
- ガイドラインをツール内で確認可能
- アノテーションの品質と一貫性を向上

#### コメント機能
- 各スパンに対してメモ形式でコメントや注釈を記録
- 疑問点や注意事項を残せる
- アノテーション作業の文脈を保存

## 現時点で不要な機能

以下の機能は複雑さやスコープの観点から、初期バージョンでは実装しない:

### バージョン管理系
- アノテーション履歴・バージョン管理
- 変更履歴の保存
- データバックアップ（自動保存、定期バックアップ）

### 協働作業系
- 複数アノテーターのサポート
- アノテーター間の一致率（IAA）計算

### UI設定
- テーマ・カラースキーマ（ダークモード）
- → ライトテーマのみ提供

## 開発方針

1. **シンプルさを優先**: 初期バージョンは機能を絞り込み、コア機能の完成度を高める
2. **段階的な拡張**: 基本機能が安定してから追加機能を検討
3. **ユーザーフィードバック重視**: 実際の使用感をもとに改善を重ねる
